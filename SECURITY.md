
# Beveiligingsbeleid

Heb je een beveiligingsprobleem gevonden op foxxware.nl of in software van FoxxWare? Laat het ons weten, dan kijken we er zo snel mogelijk naar.

**Meld het via e-mail:** [info@foxxware.nl](mailto:info@foxxware.nl)

Maak er liever geen openbare issue van, zodat we het eerst kunnen oplossen.

Zet in je melding:

- waar het probleem zit (URL, repository of onderdeel);
- hoe we het kunnen nagaan of reproduceren;
- wat de mogelijke gevolgen zijn.

Onze machineleesbare contactgegevens staan in [security.txt](https://foxxware.nl/.well-known/security.txt).
