# FoxxWare

**Maatwerksoftware die je team uit zichzelf gebruikt.**

We bouwen maatwerksoftware voor bedrijven van 20 tot 200 mensen in installatie, logistiek, groothandel, productie, zorg en uitzendwerk. Software die technisch prima werkt, wordt op de werkvloer vaak alsnog omzeild. Daarom ontwerpen we vanuit de mensen die de tool elke dag moeten openen.

## Hoe we werken

1. **Digitaal koffietje.** Twintig minuten online kennismaken.
2. **Bezoek op locatie.** We kijken mee waar het werk gebeurt.
3. **Impact Analyse.** In twee weken brengen we in kaart waar de tijd weglekt en wat dat kost. Vast bedrag van €1500.
4. **Offerte.** Een concreet voorstel met prijs.

De eerste twee stappen kosten niets. Daarna bouwen we in sprints van drie weken, en na elke stap beslis je zelf of we doorgaan.

De techniek volgt de situatie: een webapplicatie, een mobiele app, een koppeling tussen systemen of een desktopprogramma. Meestal hoeft er niets weg.
